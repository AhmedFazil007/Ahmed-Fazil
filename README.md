## How I approach a project

I usually start with a question, clean or check the data, build the analysis, and then ask what the findings could mean for a decision. I try to separate **what the data shows** from **what I think is worth investigating next**.

**Tools I work with:** Excel, Power BI, SQL and Python. My projects include dashboards, KPI reporting, data checks, scenario analysis and written business insights.
